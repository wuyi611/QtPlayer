## 八、如何查询

```bash
# 查某个 QML 名称对应哪个 C++ 类
grep -rn 'qmlRegisterType.*"名称"' --include="*.cpp"

# 查某个 C++ 类在 QML 中叫什么
grep -rn 'qmlRegisterType<类名>' --include="*.cpp"

# 查信号发射者
grep -rn 'emit 信号\|\.信号(' --include="*.cpp" --include="*.js" --include="*.qml"

# 查 connect 位置
grep -rn '信号名\.connect(' --include="*.js" --include="*.qml"

# 查 QML 控件 id 定义处
grep -rn 'id:\s*控件的id' --include="*.qml"

# 查 signal/property 声明
grep -rn 'signal 信号名\|property.*属性名' --include="*.qml" --include="*.h"
```
