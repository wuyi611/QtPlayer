# 自定义控件清单 (Custom Controls Inventory)

> 本文档统计项目中所有"自定义控件"，包括 **QML 自定义组件**（`src/view/*.qml`）与 **C++ 注册到 QML 的类型**（`qmlRegisterType` / `setContextProperty` / 命名空间导出）两类，并列出每个 QML 文件各自使用到的自定义控件。

## 一、自定义控件总目录

### A. QML 自定义组件（`src/view/`，25 个）

| 组件 | 作用 | 内部实现 |
| --- | --- | --- |
| `AnimatedButton` | 图标按钮（悬停/移出变色动画） | `ButtonColorAnimation`×2 + Image + MouseArea |
| `ButtonColorAnimation` | 颜色动画工具 | `PropertyAnimation`(color, 100ms) |
| `RoundImage` | 圆形图片（边缘可调 `edge`） | `ShaderEffect` + roundImage.vert/frag.qsb |
| `FilterItem` | 滤镜缩略图项 | Image + Text + MouseArea |
| `FiltersWindow` | 滤镜选择窗口 | ScrollView + Grid + Repeater(FilterItem) |
| `SpeedMenu` | 倍速子菜单（内置纯音频禁 8 倍速警告窗） | Menu + MenuItem |
| `TrackItem` | 音轨菜单项 | MenuItem 封装（trackID/trackName） |
| `CurrentFileItem` | "最近打开"菜单项 | MenuItem 封装（filePath/fileName） |
| `OutputDevice` | 输出设备菜单项 | MenuItem 封装（deviceName） |
| `DBus` | macOS 菜单栏 | MenuBar + Menu + MenuItem + Instantiator |
| `MediaInfo` | 媒体信息窗口 | ScrollView + ListView（Controller 部分已注释） |
| `AdditionalSettings` | 播放设置窗（亮度/饱和度/对比度/音调） | TabBar + StackLayout + Slider + Button |
| `Wave` | 音频可视化 + 歌词页 | RoundImage + WaveView + LyricsData + Flickable |
| `PonyFooter` | 底部控制栏 | AnimatedButton×9 + Thumbnail + Slider |
| `PonyBody` | 主体区（⚠ 孤儿文件，未被引用） | SwipeView + HurricanePlayer |
| `IssueWindow` | 崩溃上报窗口 | Button + crash_reporter |
| 8×`*SizeChange` | 无边框窗口 8 方向缩放手柄 | Rectangle + MouseArea → `startSystemResize` |

### B. C++ 注册的自定义控件

| QML 类型 | 注册位置 | 作用 | 主要接口 |
| --- | --- | --- | --- |
| **`HurricanePlayer`**（类 `Hurricane`） | `players.cpp` `qmlRegisterType` | 播放核心控件（视频渲染节点 `Fireworks` 子类） | `openFile/start/pause/seek/setSpeed/setVolume/setPitch/setTrack/setCurrentOutputDevice/toggleBackward/hasVideo/getAudioDuration`；属性 `state/speed/pitch/track/tracks/audioDeviceList/backwardStatus/brightness/contrast/saturation/keepFrameRate`；信号 `openFileResult/resourcesEnd/stateChanged` |

| **`WaveView`** | `main.cpp` | 波形可视化 | `tryLoadLyrics/readLyrics/setRadiusRatio`；属性 `radiusRatio/player/lyricsDataName` |
| **`LyricsData`** | `main.cpp` | 歌词数据模型 | `sentences`(ListProperty\<LyricSentence\>)、`lyricsChange` |

| **`Controller`** | `main.cpp` | 媒体库控制器（后台线程） | `recentFiles`；`sendExtractRequirement/sendRemoveRequirement/sendGetInfoRequirement/getSimpleListItemList/getListItemInfo/updateRecentFile`；信号 `finishExtractItems/finishGetInfo` |
| **`PlayList`** | `main.cpp` | 媒体库（SQLite/文件扫描），被 Controller 间接使用 | QML 中未直接实例化 |
| **`SimpleListItem`** | `main.cpp` | 播放列表简单条目 | `getFileName/getFilePath/getIconPath` |
| **`crash_reporter`**（上下文属性） | `main.cpp` | 崩溃上报 | `crashMessage/openIssueBrowser/copyLogPath/restartApplication` |
| **`hotLoader`**（上下文属性） | `main.cpp` | QML 热重载 | `reload()/crash()`（测试用） |
| **`PonyPlayerNS`**（命名空间） | `main.cpp` | 错误码枚举 | `FAILED/VIDEO/AUDIO` 等 |

> 注：`mediaLibController` 不是上下文属性，而是 main.qml 中 `Controller { id: mediaLibController }` 的实例。

## 三、要点补充

- **动态创建**：`interfacefunctions.js` 用 `Qt.createComponent` 把 `TrackItem`/`OutputDevice`/`CurrentFileItem` 挂进 main.qml 的 `trackmenu`/`devicesMenu`/`currentFilePathList`；`DBus.qml` 由 main.qml（macOS 分支）和 JS 双处动态创建。
- **依赖链**：`main.qml` → `PonyFooter` → `AnimatedButton` → `ButtonColorAnimation`；`main.qml` → `Wave` → `RoundImage`；`main.qml` → `FiltersWindow` → `FilterItem`。
- **C++ 控件与 QML 的桥接方式**：`HurricanePlayer`/`Thumbnail`/`WaveView`/`Controller` 等通过 `qmlRegisterType` 成为可实例化 QML 类型；`crash_reporter`/`hotLoader` 通过 `setContextProperty` 作为全局上下文属性；`PonyPlayerNS` 通过 `qmlRegisterUncreatableMetaObject` 导出枚举。
- **遗留提醒**：`PonyBody.qml` 未被任何文件引用（main.qml 已内联重写），但仍编译进 QML 模块，可清理。
