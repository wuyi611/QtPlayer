# PonyPlayer 项目框架文档

## 一、项目概览

PonyPlayer 是一个基于 **Qt 6 + FFmpeg + QML** 的跨平台音视频播放器。采用**分层异步架构**，UI 层（QML）与后端（C++ 解码/渲染）之间通过 Qt 信号槽机制通信，核心播放引擎运行在独立线程中。

```
平台: Windows / macOS / Linux
语言: C++17 + QML + JavaScript
构建: CMake + Qt 6
解码: FFmpeg (libavformat / libavcodec / libavutil / libswscale / libswresample)
音频: SDL2 / 自定义 AudioSink
```

## 三、模块详解

### 3.1 QML UI 层 (`src/view/`)

| 文件 | 类型 | 职责 |
|------|------|------|
| `main.qml` | 根 Window | 主窗口，定义 `mainWindow` id，声明所有顶层信号 |
| `PonyBody.qml` | Rectangle | 视频播放区域容器，内嵌 `HurricanePlayer` |
| `PonyFooter.qml` | 底部控制栏 | 播放/暂停、进度条、音量、切歌等控制按钮 |
| `Wave.qml` | 频谱可视化 | 音频波形 + 歌词显示 |
| `FiltersWindow.qml` | 滤镜窗口 | 视频滤镜选择面板 |
| `MediaInfo.qml` | 媒体信息 | 显示当前视频的编码参数详情 |
| `SpeedMenu.qml` | 倍速菜单 | 播放速度选择（0.5x ~ 2x） |
| `DBus.qml` | macOS 菜单栏 | macOS 系统菜单栏集成 |
| `IssueWindow.qml` | 崩溃报告 | 程序崩溃时的错误报告界面 |
| `interfacefunctions.js` | JS 函数库 | 40个界面交互函数，含播放控制、音量、滤镜、歌词等 |

**mainWindow（root Window）** 定义了 13 个顶层信号，作为 UI 层与播放器后端之间的唯一通信入口。

### 3.2 播放器组件层 (`src/player/`)

#### 继承关系

```
QQuickItem
  └── Fireworks          → OpenGL 渲染器管理、滤镜加载
        └── Hurricane    → 播放器状态机、QML 接口暴露
```

#### Hurricane — 播放器核心（QML 可见的 HurricanePlayer）

```
状态机模型:
  INVALID ──openFile──→ LOADING ──(加载完成)──→ PAUSED ⇄ PLAYING
     ↑                                                ↓
     └────────── CLOSING ←── close() ──────────────────┘

瞬时状态（前端发起但后端未完成）:
  - PRE_PLAY: 即将播放
  - PRE_PAUSE: 即将暂停
  - CLOSING: 正在关闭
  - LOADING: 正在加载
```

| 分类 | 方法 | 功能 |
|------|------|------|
| **文件** | `openFile()` / `close()` | 打开/关闭视频文件 |
| **播放** | `start()` / `pause()` | 播放/暂停，带状态保护 |
| **定位** | `seek(pos)` | 跳转到指定位置 |
| **音视频** | `setVolume()` / `setPitch()` / `setSpeed()` | 音量/音调/速度 |
| **音轨** | `getTracks()` / `setTrack()` | 获取/切换音轨 |
| **方向** | `forward()` / `backward()` / `toggleBackward()` | 正放/倒放/切换 |
| **其他** | `getPTS()` / `getVideoDuration()` / `hasVideo()` | 查询播放状态 |

#### FrameController — 帧调度器

运行在独立线程 `FRAME` 中，是解码器（Demuxer）与输出（Playback）之间的协调中心：

```
Hurricane ──signal──→ FrameController ──signal──→ Demuxer (解码)
                                    ──signal──→ Playback (输出)
```

- **打开文件**: `signalOpenFile → Demuxer::openFile → 设置输出格式 → 启动解码 → 预览第一帧`
- **音轨切换**: `暂存当前位置 → 停止播放 → 切换轨道 → seek 恢复`
- **正倒放切换**: `暂存位置 → forward/backward → seek 恢复`

#### Fireworks — OpenGL 渲染基类

- 管理 `FireworksRenderer`（自定义 QSG 渲染器）
- 与 `QQuickWindow::beforeSynchronizing` / `beforeRendering` 同步
- 加载视频滤镜（LUT）：读取 `assets/filters/*.json`，支持 Contrast / Flim / Video

#### Playback — 音视频同步输出

- 管理音频 `AudioSink` 和视频帧的同步播放
- 维护解码帧缓存，支持音画同步（时钟同步）
- 音频设备热插拔检测

#### Thumbnail / Preview — 缩略图预览

- `Thumbnail`：QML 可见的缩略图组件（悬停进度条时的预览图）
- `Preview`：独立的解码器实例，生成预缩略图帧

### 3.3 解码层 (`src/decoder/`)

```
Demuxer ←→ DecodeDispatcher
                ├── VirtualDecoder (抽象)
                │     ├── Decoders (单线程正放)
                │     └── Previewer (缩略图解码)
                └── ReverseDecodeDispatcher (倒放)
                      └── Backward (反向解码)
```

| 文件 | 类 | 职责 |
|------|-----|------|
| `demuxer.hpp` | `Demuxer` | 封装 FFmpeg 解封装（avformat），管理流和轨道 |
| `frame.hpp` | `Frame` / `VideoFrameRef` / `AudioFrameRef` | 音视频帧数据结构，引用计数管理 |
| `dispatcher.hpp` | `DecodeDispatcher` | 多线程解码调度，管理解码线程池 |
| | `ReverseDecodeDispatcher` | 倒放解码调度器 |
| `forward.hpp` | — | 正放解码器实现 |
| `backward.hpp` | — | 倒放解码器实现（反向 seek 和解码） |
| `previewer.hpp` | — | 缩略图预览解码器 |
| `virtual.hpp` | — | 虚拟解码器基类 |

### 3.4 音频输出层 (`src/audiosink/`)

| 文件 | 职责 |
|------|------|
| `audiosink.hpp` | 音频输出设备封装，支持 SDL2 / 自定义输出 |
| `audioformat.hpp` | 音频格式定义（采样率、通道数等） |
| `hotplug.hpp` | 音频设备热插拔检测 |

### 3.5 媒体库层 (`src/playlist/`)

```
QML (Controller)  ──→ Controller ──→ PlayList (工作线程) ──→ KV Engine (SQLite)
                        ↑                  ↑
                  信号槽跨线程          数据库 CRUD
```

| 文件 | 类 | 职责 |
|------|-----|------|
| `controller.h/cpp` | `Controller` | 媒体库的 QML 接口，管理最近播放文件 |
| `playlist.h/cpp` | `PlayList` | 数据库操作类，运行在独立线程 |
| `playlist.h` | `PlayListItem` | 媒体条目完整信息（含视频/音频编码参数） |
| | `simpleListItem` | 媒体条目简化信息（文件名、路径、图标） |
| `kv_engine.h/cpp` | `KV Engine` | 通用 KV 存储引擎（基于 SQLite） |
| `info_accessor.h/cpp` | `InfoAccessor` | 媒体信息提取器（通过 FFmpeg 获取编码参数） |

**线程模型**: `PlayList` 通过 `moveToThread` 移至 `listOPThread`，所有数据库操作在后台线程执行，不阻塞 UI。

### 3.6 波形/歌词层 (`src/wave/`)

| 文件 | 类 | 职责 |
|------|-----|------|
| `wave.hpp` | `WaveView` | 音频波形可视化 QQuickItem |
| `lyrics.h/cpp` | `LyricsData` / `LyricSentence` | 歌词数据模型（关联 `.lrc` 文件） |

### 3.7 工具层 (`src/utils/`)

| 文件 | 用途 |
|------|------|
| `logger.h/cpp` | 自定义 Qt 日志处理器，输出到文件 |
| `ponyplayer.h` | 项目级常量定义（线程名、枚举、资产路径等） |
| `countdown_latch.h/cpp` | 线程同步原语（类似 std::latch） |
| `twins_queue.hpp` | 双缓冲无锁队列（解码帧缓存） |
| `platform.hpp` | 平台适配（路径拼接、文件系统等） |

## 四、线程模型

```
┌─────────────────┐
│  主线程 (GUI)    │ ← QML 渲染、事件循环
│  QML Engine      │
├─────────────────┤
│  FRAME 线程      │ ← FrameController + Demuxer + Playback + AudioSink
│  解码、同步、输出  │
├─────────────────┤
│  listOPThread   │ ← PlayList 数据库操作
│  SQLite CRUD     │
├─────────────────┤
│  解码线程池       │ ← DecodeDispatcher 管理的 worker 线程
│  FFmpeg 解码      │
└─────────────────┘
```

关键连接方式：
- **主线程 → FRAME 线程**: Qt::QueuedConnection（跨线程）
- **FRAME 内部**: Qt::DirectConnection（同线程）
- **FRAME → 主线程**: Qt::QueuedConnection（帧回调、状态通知）
- **Seek 操作**: Qt::BlockingQueuedConnection（需要同步返回结果）
- **QML ↔ Hurricane**: 直接调用 Q_INVOKABLE 方法（同线程，异步处理）

## 五、数据流

### 5.1 打开文件流程

```
QML: 用户选择文件
  │
  ▼
mainWindow.openFile(path)  ← QML signal
  │  connect (JS/QML)
  ▼
videoArea.openFile(path)   ← Hurricane Q_INVOKABLE
  │
  ├─ [PLAYING] → emit pause() → emit close()  ← 自动关闭旧文件
  ├─ [PAUSED]  → emit close()
  │
  ├─ INVALID / CLOSING → 进入加载流程
  │
  ▼
emit signalOpenFile(path)
  │  Qt::AutoConnection → QueuedConnection (跨线程)
  ▼
FrameController::openFile()           [FRAME 线程]
  │
  ▼
Demuxer::openFile()                   [FFmpeg 解封装]
  │  openFileResult callback
  ├─ m_playback->setDesiredFormat()   配置输出格式
  ├─ m_demuxer->setOutputFormat()
  ├─ m_demuxer->start()               开始解码
  ├─ m_playback->clearCacheFrame()
  └─ m_playback->showFrame()          渲染第一帧
       │
       ▼
emit openFileResult(SUCCESS) → Hurricane::slotOpenFileResult
  │  state → PAUSED, 更新 duration, tracks
  ▼
QML 显示第一帧，等待用户点击播放
```

### 5.2 播放/暂停流程

```
用户点击播放
  │
  ▼
Hurricane::start()
  ├─ state → PRE_PLAY
  └─ emit signalStart()
       │  → FrameController::start()
       │    → Playback::showFrame()  → 开始音视频输出循环
       ▼
  emit playbackStateChanged(PLAYING)
       │  → Hurricane::slotPlaybackStateChanged()
       │    state → PLAYING
       ▼
  QML 更新播放状态 UI


用户点击暂停
  │
  ▼
Hurricane::pause()
  ├─ state → PRE_PAUSE
  └─ emit signalPause()
       │  → FrameController::pause()
       │    → Playback 停止输出
       ▼
  emit playbackStateChanged(PAUSED)
       │  → Hurricane::slotPlaybackStateChanged()
       │    state → PAUSED
       ▼
  QML 更新暂停状态 UI
```

### 5.3 播放进度更新定时器

```
QML Timer (每帧/每秒)
  │
  ▼
timerOnTriggered()                    [interfacefunctions.js:379]
  ├─ mainWindow.currentTime = videoArea.getPTS()
  ├─ isBoundary() 检查是否到达视频边界
  └─ triggerLyricUpdate() 同步歌词滚动
```

## 七、关键设计决策

1. **异步状态机**: Hurricane 使用瞬时状态（PRE_PLAY, PRE_PAUSE, CLOSING）处理前端请求与后端响应之间的时间差，避免重复操作
2. **QPrivateSignal**: 所有跨线程的内部信号带 `QPrivateSignal()` 标记，仅允许 Hurricane 类自身发射
3. **BLOCKING_QUEUED_CONNECTION**: Seek 操作使用阻塞队列连接，确保同步返回
4. **双缓冲无锁队列**: 解码帧与渲染帧之间通过 `TwinsQueue` 交换，避免锁竞争
5. **自动关闭**: `openFile` 默认 `autoClose=true`，自动处理旧文件的 pause→close→open 链条
6. **崩溃恢复**: 注册 SIGABRT/SIGSEGV 处理器，启动独立的崩溃报告进程
