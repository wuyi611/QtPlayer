## 1. 项目入口 (`src/`)

### `main.cpp`
程序入口点，无类定义，包含以下关键函数：

| 函数 | 说明 |
|------|------|
| `main(argc, argv)` | 启动流程：注册崩溃处理 → 设置 OpenGL 3.3 Core Profile → 注册 QML 类型 → 安装日志 → 创建 HotLoader → 加载 `main.qml` |
| `signalHandler(signum)` | SIGABRT/SIGSEGV 信号处理，启动崩溃报告子进程后退出 |
| `startReporterProcess(message)` | 通过 `QProcess::startDetached` 启动自身子进程进入崩溃报告模式 |
| `reportErrorMain(argc, argv)` | 崩溃报告模式入口，解析 `--crash-report` 等参数，加载 `IssueWindow.qml` |

**注册的 QML 类型**: `HurricanePlayer`, `Thumbnail`, `Controller`, `PlayList`, `SimpleListItem`, `WaveView`, `LyricsData`, `LyricSentence`, `PonyPlayerNS`（枚举命名空间）

### `include/twins_queue.hpp`
#### `TwinsBlockQueue<T>`
双生阻塞队列模板 — 一对队列共享一个互斥锁和条件变量，用于视频帧和音频帧的同步出队。

| 方法 | 说明 |
|------|------|

| `push(item)` | 入队，若队列已关闭则释放 item |
| `remove()` | 出队并移除（阻塞） |
| `viewFront()` | 查看队首但不出队 |
| `skip(predicate)` | 跳过满足条件的元素 |
| `close()/open()` | 关闭/打开队列（关闭后 push 会释放 item） |
| `setEnable(bool)` | 启用/禁用队列 |
| `clear()` | 清空队列 |

### `demuxer.hpp`
#### `Demuxer : QObject`
**解封装与解码调度核心**，运行在 DECODER 线程。内部持有正放/倒放两套解码管线，通过 `m_worker` 指针切换。

| 成员 | 说明 |
|------|------|
| `getPicture()` | 获取当前视频帧（出队并移除） |
| `frontPicture()` | 查看队首视频帧 PTS（不出队） |
| `skipPicture(pred)` | 跳过满足条件的视频帧 |
| `getSample()` | 获取当前音频帧（出队并移除） |
| `frontSample()` | 查看队首音频帧 PTS（不出队） |
| `skipSample(pred)` | 跳过满足条件的音频帧 |
| `audioDuration()` / `videoDuration()` | 获取音/视频总时长 |
| `getTracks()` | 获取音轨列表 |
| `isBackward()` | 当前是否为倒放模式 |
| `hasVideo()` | 当前文件是否有视频流 |
| `pause()` | 暂停解码器（向 DecodeThread 发送暂停信号） |
| `flush()` | 清空解码缓冲队列（阻塞等待） |
| `start()` | 恢复解码器运行 |
| `setEnableAudio(bool)` | 启用/禁用音频解码 |
| `getInputFormat()` | 获取源文件音频格式 |
| `setOutputFormat(fmt)` | 设置重采样目标格式 |

**槽函数**:
| 槽 | 说明 |
|------|------|
| `openFile(fn)` | 打开文件 → 创建 DecodeDispatcher + ReverseDecodeDispatcher → 发射 `openFileResult` |
| `seek(secs)` | 跳转进度 |
| `setAudioIndex(idx)` | 设置音频流索引 |
| `setTrack(i)` | 切换音轨 |
| `backward()` | 切换到倒放模式 |
| `forward()` | 切换到正放模式 |
| `close()` | 关闭文件，销毁解码调度器 |

**信号**: `openFileResult(result, QPrivateSignal)`

**典型操作流程**:
```
seek: pause() → seek() → flush() → start()
切轨: pause() → setTrack() → flush() → start()
方向切换: pause() → backward()/forward() → seek() → flush() → start()
```

### `private/dispatcher.hpp`
#### `OpenFileResultType` (enum namespace)
文件打开结果: `FAILED`, `VIDEO`, `AUDIO`。

#### `StreamInfo` (struct)
流元数据（语言标签 + 时长）；`getFriendName()` 生成音轨菜单显示名。

#### `DemuxDispatcherBase : QObject`
解码调度器抽象基类。提供 FFmpeg 格式上下文管理、虚拟的解码控制接口（`statePause/flush/stateResume/seek/getPicture/...`）。

#### `DecodeDispatcher : DemuxDispatcherBase`
**正向解码调度器**。通过 `av_read_frame` 读包 → 分发给 `DecoderImpl<Audio>` / `DecoderImpl<Video>` → 帧入 `TwinsBlockQueue`。处理 EOF、seek、音轨切换、音频启用/禁用。

#### `ReverseDecodeDispatcher : DemuxDispatcherBase`
**反向解码调度器**。使用 `ReverseDecoderImpl` 以 5 秒为片段缓冲帧 → 反转 → 逐片段后退播放。管理片段跳转和 EOF 回绕。

---

### `private/decoders.hpp`
#### `IDemuxDecoder`
解码器抽象接口。

| 方法 | 说明 |
|------|------|
| `accept(pkt, interrupt)` | 接受并解码一个数据包 |
| `flushFFmpegBuffers()` | 清空 FFmpeg 内部缓冲 |
| `getPicture() / getSample()` | 获取解码帧 |
| `viewFront() / skip()` | 查看/跳过队列中的帧 |
| `duration()` | 获取流时长 |
| 倒放相关 | `setFollower`, `pushFrameStack`, `getLastPts`, `clearFrameStack`, `setStart`, `nextSegment` |
| `getInputFormat() / setOutputFormat()` | 音频格式管理 |

#### `DecoderType` (enum)
`Audio`, `Video`, `Common`。

#### `DecoderContext`
单个流的解码上下文: AVCodec + AVCodecContext + AVFrame。

---

### `private/forward.hpp`
#### `DecoderImpl<Type> : DecoderContext, IDemuxDecoder`
通用正向解码器模板 — `avcodec_send_packet/receive_frame` 循环，帧入 TwinBlockQueue。

#### `DecoderImpl<Audio>` (特化)
音频解码器，通过 `SwrContext` 重采样到目标格式。

#### `DecoderImpl<Video>` (特化)
视频解码器，缓存首帧封面图（PTS<0 时）。

---

### `private/backward.hpp`
#### `ReverseDecoderImpl<Type> : IDemuxDecoder`
反向解码器模板。核心机制：以 5 秒为窗口缓冲帧 → `pushFrameStack` 反转帧序 → 逐帧出队。

#### `ReverseDecoderImpl<Audio>` (特化)
反向音频解码器 — **原地反转 PCM 采样数据** (`reverseSample`)，并偏移 PTS。

#### `ReverseDecoderImpl<Video>` (特化)
反向视频解码器 — 从反转队列出队视频帧。

---

### `private/previewer.hpp`
#### `Previewer : DemuxDispatcherBase`
**缩略图预览解码器**。按需解码单帧：`previewRequest(pos)` → seek 到目标位置 → 解码直到 PTS ≥ pos → 返回 `VideoFrameRef`。用于进度条悬停预览。

---

### `private/virtual.hpp`
#### `VirtualVideoDecoder : IDemuxDecoder`
**虚拟视频解码器**（纯音频文件的占位视频）。`getPicture()` 返回有效但为空的帧，`duration()` = 音频时长，使纯音频文件也能走统一的播放流程。

## 10. 线程架构总览

```
┌─────────────────────────────────────────────────┐
│                   MAIN 线程                       │
│  main.qml / Hurricane / Fireworks / Controller  │
│  QML UI 渲染 + 用户交互 + 媒体库操作              │
└────────────┬────────────────────┬───────────────┘
             │                    │
    signal/slot (Queued)  signal/slot (Queued)
             │                    │
             ▼                    ▼
┌────────────────────┐  ┌──────────────────────┐
│   FRAME 线程        │  │   listOPThread       │
│   FrameController   │  │   PlayList           │
│   解码←→输出协调    │  │   SQLite 数据库操作   │
└──┬────────────┬─────┘  └──────────────────────┘
   │            │
   │ (Queued)   │ (Queued/Blocking)
   │            │
   ▼            ▼
┌──────────┐ ┌──────────────┐
│ DECODER  │ │  PLAYBACK    │
│ Demuxer  │ │  Playback    │
│ 正放/倒放│ │  PonyAudioSink│
│ FFmpeg   │ │  PortAudio   │
└──────────┘ └──────┬───────┘
                    │
                    │ DirectConnection
                    ▼
              ┌──────────────┐
              │ RENDER 线程   │
              │ Fireworks    │
              │ Renderer     │
              │ OpenGL 3.3   │
              └──────────────┘
```

| 线程 | 类 | 职责 |
|------|------|------|
| MAIN | Hurricane, Fireworks, Controller | UI + 用户交互 + 媒体库 |
| FRAME | FrameController | 解码→输出的协调桥梁 |
| DECODER | Demuxer, DecodeDispatcher, ReverseDecodeDispatcher | FFmpeg 解封装与解码 |
| PLAYBACK | Playback, PonyAudioSink | 音视频输出 + PortAudio |
| RENDER | FireworksRenderer | OpenGL YUV→RGB 渲染 |
| PREVIEW | Previewer | 缩略图按需解码 |
| listOPThread | PlayList, PonyKVConnect | SQLite 数据库操作 |
