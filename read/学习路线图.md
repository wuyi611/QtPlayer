# PonyPlayer 项目学习路线图

> 一份结构化的项目学习计划，从零基础到深入理解各子系统。

---

## 学习原则

1. **自顶向下**：先从宏观架构入手，再逐层深入细节
2. **追踪数据流**：以"打开一个文件并播放"为主线索，贯穿全项目
3. **先读文档，后读代码**：项目已有较完善的文档体系
4. **边读边跑**：结合调试运行加深理解

**目标**: 知道每个技术解决什么问题。

## 第五阶段：专题深入（按需选择）

### 5.1 线程安全机制

PonyPlayer 涉及 5+ 个线程，理解其同步策略很有价值：

| 机制 | 使用场景 | 示例代码 |
|------|---------|---------|
| `std::atomic<bool>` | 中断标志、播放状态 | `DecodeDispatcher::interrupt` |
| `std::mutex` + `std::condition_variable` | 同步等待 | `Playback::syncTo()` |
| `Qt::QueuedConnection` | 跨线程信号槽 | 主线 → FRAME → DECODER |
| `Qt::BlockingQueuedConnection` | seek 同步返回 | `signalDecoderSeek` |
| `Qt::DirectConnection` | 渲染线程同步 | `beforeSynchronizing → sync()` |
| `PONY_GUARD_BY(thread)` | 编译期文档标注 | 参见 [ponyplayer.h](..\src\utils\include\ponyplayer.h) |

### 5.2 倒放实现原理

这是项目的技术亮点之一，理解它的分段策略：
1. 从目标位置向前 seek `interval` (5 秒)
2. 正向解码这些帧，推入 stack
3. 当 leader (视频) 的 lastPts ≥ from 时，从 stack 弹出（后进先出 = 倒序输出）
4. follower (音频) 同步弹出，且音频 sample 需要做字节级反转
5. 当 from 退到 0 时结束

### 5.3 音视频同步

`Playback::syncTo()` 实现基于音频时钟的同步：
- 纯音频：按固定帧率 (30fps) 休眠
- 有视频：计算视频帧 PTS 与音频播放位置的时间差，按差值休眠

### 5.4 高速播放策略

当倍速 > 4x 时，进入特殊模式：
- 音频被阻塞 (`m_blockingState = true`)，输出静音
- 视频帧按 skip 逻辑快速跳帧
- 倍速回到 ≤4x 时，重新同步音频并启用

## 辅助工具建议

1. **IDE**: 使用 CLion (项目推荐的 IDE)，利用其"查找引用"、"跳转定义"功能
2. **调试**: 在关键路径设断点（如 `Hurricane::openFile`、`FrameController::seek`、`Playback::onWork`），观察实际运行时序
3. **日志**: 代码中有大量 `qDebug()` 输出，运行时观察日志输出可快速理解执行流程
4. **画图**: 用 draw.io 或 Excalidraw 自己画数据流图，比读文档记得更牢
