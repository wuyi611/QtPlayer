# PonyPlayer 打开文件完整流程

## 概览

从用户选择文件到视频第一帧显示，共涉及 **6 层、3 个线程**：

```
QML UI → Hurricane → FrameController → Demuxer → FFmpeg → 回调返回
 主线         主线          FRAME线程        DECODER线程   DECODER线程
```

### 2.1 自动关闭旧文件（autoClose=true）

```
当前状态 PLAYING / PRE_PLAY:
  → emit pause()                // 同步调用 Hurricane::pause()
    → state = PRE_PAUSE
    → emit signalPause()        // → FrameController::pause() [FRAME线程]
                                  → m_playback->pause()

当前状态 PAUSED / PRE_PAUSE:
  → emit close()                // 同步调用 Hurricane::close()
    → state = CLOSING
    → setVideoFrame(VideoFrameRef())  // 清空当前视频帧
    → emit signalClose()         // → FrameController::close()  [FRAME线程]
                                  → m_demuxer->close()
                                  → m_playback->stop()
                                  // Demuxer::close() 内部:
                                  //   m_worker = nullptr
                                  //   m_forward->statePause() + deleteLater()
                                  //   m_backward->statePause() + deleteLater()
```

### 2.2 打开新文件

```
进入条件: state == INVALID 或 state == CLOSING
  ├─ state = LOADING
  ├─ emit stateChanged()                → QML 可感知"加载中"
  ├─ backwardStatus = false
  ├─ emit backwardStatusChanged()
  └─ emit signalOpenFile(path)          → FrameController::openFile()  [FRAME线程]
```

> **注意**: 如果 state 是其他值（如 LOADING），则静默返回，本次 openFile 被丢弃。

## 阶段四：Demuxer::openFile() — FFmpeg 解封装

文件: [src/decoder/demuxer.hpp:210](../src/decoder/demuxer.hpp#L210)

```cpp
void openFile(const std::string &fn) {
    std::unique_lock lock(m_workerLock);

    // ① 检查是否已有文件打开，有则返回 FAILED
    if (m_worker) {
        emit openFileResult(PonyPlayer::OpenFileResultType::FAILED, QPrivateSignal());
        return;
    }

    // ② 创建正放 + 倒放解码调度器
    try {
        m_forward = new DecodeDispatcher(fn, result, ...);   // ← FFmpeg 解封装在这里
        m_backward = new ReverseDecodeDispatcher(fn, this);  // ← 倒放解码器
        m_worker = m_forward;      // 默认正放
    } catch (std::runtime_error &ex) {
        // 打开失败 → 清理 → 返回 FAILED
        m_worker = m_backward = m_forward = nullptr;
        emit openFileResult(result, QPrivateSignal());
        return;
    }

    lock.unlock();
    // ③ 启动解码器线程
    m_worker->stateResume();
    // ④ 返回成功
    emit openFileResult(result, QPrivateSignal());
}
```

### DecodeDispatcher 内部做了什么？

```
DecodeDispatcher 构造函数:
  1. avformat_open_input()  → 打开媒体文件
  2. avformat_find_stream_info() → 探测流信息（视频/音频/字幕轨道）
  3. 为每个流创建并打开 avcodec (avcodec_open2)
  4. 读取第一帧（用于获取视频尺寸、时长等元信息）
  5. 创建解码 worker 线程池
```

## 阶段五：FrameController 接收结果 — 配置 + 渲染第一帧

文件: [src/player/framecontroller.hpp:42](../src/player/framecontroller.hpp#L42)

connect(m_demuxer, &Demuxer::openFileResult, this, [this](OpenFileResultType result) {
    if (result != FAILED) {
        // ① 设置音频输入输出格式
        m_playback->setDesiredFormat(m_demuxer->getInputFormat());
        //    → m_audioSink->setFormat(format)  配置 AudioSink 采样率/通道
        m_demuxer->setOutputFormat(m_playback->getDeviceFormat());
        //    → 设置 resampler 的输出格式

        // ② 启动解码器，开始填充帧缓冲
        m_demuxer->start();
        //    → m_worker->stateResume()  唤醒解码器线程

        // ③ 清空播放缓存中的旧帧
        m_playback->clearCacheFrame();

        // ④ 显示第一帧
        m_playback->showFrame();
        //    → emit showFirstVideoFrame()
        //      → Playback 内部从 Demuxer 取一帧 → emit setPicture(frame)
        //        → FrameController::setPicture → 主线程拿到 VideoFrameRef
    }
    // ⑤ 结果向上传回 Hurricane
    emit openFileResult(result);

## 阶段六：Hurricane::slotOpenFileResult — 状态更新 + 通知 QML

文件: [src/player/hurricane.hpp:457](../src/player/hurricane.hpp#L457)

```cpp
void slotOpenFileResult(OpenFileResultType result) {
    if (result != FAILED) {
        state = PAUSED;        // 打开成功 → 进入暂停状态（等待用户播放）
        track = 0;             // 默认第一个音轨
    } else {
        state = INVALID;       // 打开失败 → 回到无效状态
        track = -1;
    }
    emit openFileResult(result, QPrivateSignal());
    emit trackChanged();       // → QML 音轨列表更新（Q_PROPERTY tracks READ getTracks NOTIFY openFileResult）
    emit stateChanged();       // → QML 状态感知（Q_PROPERTY state READ getState NOTIFY stateChanged）
}
```

`emit stateChanged()` 触发后，QML 中绑定 `videoArea.state` 的控件可以感知到"已暂停"，并显示第一帧画面。此时用户点击播放即可开始播放。

## 关键线程和连接方式

| 跳转 | 线程跨度 | 连接类型 |
|------|---------|----------|
| Hurricane → FrameController | **主线 → FRAME** | QueuedConnection（信号槽自动） |
| FrameController → Demuxer | **FRAME → DECODER** | QueuedConnection（信号槽自动） |
| Demuxer::openFileResult → FrameController | **DECODER → FRAME** | QueuedConnection |
| FrameController::openFileResult → Hurricane | **FRAME → 主线** | QueuedConnection |

所有跨线程通信均通过 Qt 信号槽，`QPrivateSignal` 确保信号仅由所属类发射。

---

## 异常路径

| 场景 | 结果 |
|------|------|
| 文件格式不支持 / 文件损坏 | `DecodeDispatcher` 抛异常 → `openFileResult(FAILED)` → state → `INVALID` |
| 已有文件打开时再次 openFile | `Demuxer` 检测到 `m_worker` 非空 → `openFileResult(FAILED)` |
| 状态为 LOADING 时 openFile | 不进入任何 if 分支，静默返回，请求被丢弃 |
| autoClose=false 且 state 非 INVALID | 跳过 pause/close，直接检查第三个 if，通常被拒绝 |
