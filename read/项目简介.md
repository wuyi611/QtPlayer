# PonyPlayer

PonyPlayer 是一款基于 Qt6 和 FFmpeg 的跨平台媒体播放器。本项目旨在使用现代技术打造一个轻量级、可定制的播放器。

PonyPlayer 具备以下特性：
* 基于 OpenGL 的高性能渲染引擎 "Hurricane"
* 功能完善且易于使用的媒体库
* 视频与音频的独立倍速调节
* 亮度/对比度/饱和度调节及多种视频滤镜
* 帧预览功能
* 基于 QML 的 macOS 原生体验

与 VLC、mpv 等大型播放器项目相比，PonyPlayer 对开发者更加友好，便于修改和创建自定义构建版本。欢迎为本项目做出贡献！

## 使用说明

推荐使用 `CLion` 作为开发 IDE。

### 环境要求

- C++17 编译器（Windows 平台需使用 mingw64_1120）
- Qt 6.2.4 LTS
- FFmpeg n5.0.1
- Python 3.7+
- 打包所需的其他依赖

### 环境配置

```bash
python3 scripts/setup.py --qt_path <Qt 安装路径> --ffmpeg_path <FFmpeg 安装路径>
```

例如，`qt path` 为 `/Users/runner/Qt/6.2.4/macos`，`ffmpeg path` 为 `/Users/runner/FFmpeg`。

特别注意：在 Linux 平台上，将 `ffmpeg path` 设置为 `""`。

### 构建

```bash
python3 scripts/build.py
```

### 打包

打包为安装程序可能需要额外工具，详见[安装指南](https://github.com/SCUT-SE-ProjectMP/PonyPlayer/blob/main/.github/workflows/build.yml)。

```bash
python3 scripts/package.py
```

- Windows 平台使用 **NSIS** 创建 `.msi` 安装程序
- macOS 平台使用 **create-dmg** 创建 `.dmg` 安装程序
- Linux 平台使用 **appimagetool** 创建 `AppImage` 安装包

## 项目结构

![结构图](README.assets/Strcutrue.svg)

### 目录结构

```
assets      --  外部资源文件
config      --  配置文件（用户配置也在此目录生成）
docs        --  文档
samples     --  用于单元测试的视频样本
thirdparty  --  第三方库源码及 CMake 脚本
scripts     --  项目辅助脚本（环境配置、构建、打包）
src         --  项目源代码，按功能划分为多个模块
```

### 模块说明

| 模块 | 说明 |
| ---- | ---- |
| **AudioSink** | 音频输出模块，集成 PortAudio。实现音量调节、变速等音频输出相关功能。 |
| **Decoder** | 媒体解码模块，集成 FFmpeg。实现解码流控制相关功能，如进度跳转（seek）。 |
| **Player** | QuickItem 模块，集成 Qt 与 OpenGL。注册自定义 QuickItem 并暴露给 QML，由 OpenGL 负责绘制。同时实现播放控制功能，接收来自 QML 的指令，经适当处理后转发至 AudioSink 和 Decoder 模块。 |
| **Playlist** | 数据持久化模块，集成 Qt SQL。基于 Qt MetaObject 的反射机制，实现零配置的数据持久化。相关数据保存至本地 SQLite 数据库。 |
| **Tests** | 单元测试。 |
| **Utils** | 工具模块，包括平台相关方法的封装和日志记录器等。 |
| **View** | 视图模块，集成 QML，实现大部分 UI 界面。UI 使用 QML 编写，简单逻辑使用 JavaScript 实现。 |
| **Wave** | 波形模块。与 Player 模块类似，集成 Qt 与 OpenGL，注册一个用于绘制环形音频"示波器"的 QuickItem。 |
